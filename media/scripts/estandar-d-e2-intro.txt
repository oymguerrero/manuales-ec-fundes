Elemento 2: construir la solución tecnológica de modernización digital con Inteligencia Artificial. Aquí la solución toma forma técnica.

Este elemento pide cuatro productos: el entorno de desarrollo configurado, la solución tecnológica con IA desarrollada, el reporte de pruebas técnicas y la documentación técnica.

Para El Surtido, la solución tiene tres componentes de IA: la captura de pedidos por WhatsApp y un formulario web, la optimización de rutas para las tres camionetas y la predicción de demanda con los tres años de pedidos. El stack es Python con FastAPI, una base de datos PostgreSQL y una interfaz web en React que los repartidores consultan en el celular.

Lo central de este elemento es que la solución funcione y quede documentada: que el backend opere, que las integraciones con IA respondan y que las pruebas lo demuestren. El despliegue en el entorno productivo de la MiPyME viene después, en el Elemento 3.
